# FDE Growth Plan

FDE Growth Plan 是一个面向 Forward Deployed Engineering（FDE，前沿部署工程）学习、实践和项目落地的开源内容仓库。

它包含两部分：

- **FDE Growth Plan Skill**：用于每日学习、能力评估、动手任务和面试准备。
- **FDE 知识库**：系统解释 FDE 如何从角色概念走向真实业务现场、AI 项目生产化、客户接管、商业价值和职业成长。

如果你只是想了解 FDE，建议先读知识库。

如果你想按周期训练自己的能力，再使用 skill。

## 适合谁读

这套内容适合：

- 想了解或转向 FDE 的产品、工程、咨询、售前、解决方案和交付人员。
- 正在做企业 AI、Agent、RAG、工作流自动化项目的团队。
- 需要把 AI 项目从 Demo 推进到生产、验收、运维和持续价值的负责人。
- 想理解 FDE 在中国市场如何落地的创业者、管理者和业务负责人。

## FDE Growth Plan Skill

这个 skill 用于可配置学习周期、每日学习推送、能力诊断、项目评审、生产检查、交付模板生成、学习笔记、项目练习、作品集和面试准备。

它覆盖 FDE 岗位定义、职业定位、4/8/12/24 周学习周期、Day 1 摸底和能力评估、Prompt/RAG/Agent/Workflow/MCP/Evals 基础、AI 产品与客户场景分析、Demo 到 Production 的生产化思维、部署、监控、成本、安全、生产就绪、客户需求发现、ROI 判断、作品集和面试准备。

使用方式：把这个文件夹安装或复制到你的 skills 目录，然后对助手说：

```text
今天的FDE学习
```

也可以直接使用这些入口：

```text
诊断我的FDE能力
评审这个FDE项目
检查我的Demo能不能上线
生成生产准入门禁矩阵
打磨FDE作品集
准备FDE面试
```

第一天会先进行摸底，了解你的当前背景、学习目标、学习周期、每天学习时长、工程和 AI 基础、偏好的行业场景、输出偏好，以及能力自评。完成摸底后，每天的学习内容会包含主题、概念讲解、案例、动手任务、验收标准和进阶思考。

`scripts/update-learning-doc.py` 可以创建或更新本地 `learning-notes.md` 学习笔记。这个文件会被 Git 忽略，因为它包含个人学习记录。

```bash
python3 scripts/update-learning-doc.py --json-file daily.json
```
