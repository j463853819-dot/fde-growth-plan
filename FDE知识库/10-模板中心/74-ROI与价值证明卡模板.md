# ROI 与价值证明卡模板

ROI 与价值证明卡用于把 FDE 项目的业务价值说清楚。

它解决的问题是：项目不是“感觉有用”，而是到底改善了哪个指标，成本是多少，是否值得继续投。

## 价值证明卡

| 字段 | 内容 |
| --- | --- |
| 项目名称 |  |
| 业务场景 |  |
| 目标角色 |  |
| 原始问题 |  |
| 基线指标 | 当前时间、成本、质量、风险或收入 |
| 改善目标 | 希望改善多少 |
| 实际结果 | 试点或生产后的指标 |
| 总拥有成本 | 人力、平台、模型、集成、运维 |
| 直接收益 | 节省工时、降低成本、提升收入 |
| 间接收益 | 风险减少、体验提升、知识沉淀 |
| 归因说明 | 哪些收益能归因于本项目 |
| 结论 | 继续、扩大、调整或停止 |

## ROI 简化计算

```text
ROI =（效率收益 + 收入提升 + 风险减少收益 - 总拥有成本）/ 总拥有成本
```

## 使用提醒

ROI 不应该上线后才算。

FDE 在选择场景时就要问：这个项目未来如何证明价值？如果基线不可测、收益不可归因、客户不愿提供数据，那就不要轻易承诺按效果付费。
