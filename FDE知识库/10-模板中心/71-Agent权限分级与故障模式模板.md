# Agent 权限分级与故障模式模板

Agent 生产化最重要的不是让它能做更多事，而是知道它被允许做什么，以及做错了怎么办。

这个模板用于记录 Agent 的工具权限、人工确认点、失败模式和应对方式。

## 工具权限分级

| 等级 | 含义 | 示例 | 是否需要人工确认 |
| --- | --- | --- | --- |
| L1 只读 | 只能查询，不改变状态 | 查询订单、读取知识库 | 否 |
| L2 建议 | 生成建议，但不执行 | 生成回复、生成工单草稿 | 视场景 |
| L3 审批后写入 | 人确认后写入业务系统 | 更新 CRM、创建工单 | 是 |
| L4 自动写入 | 低风险自动执行 | 自动打标签、发送低风险通知 | 否，但要可回滚 |

## 故障模式表

| 故障模式 | 表现 | 风险等级 | 检测方式 | 处理动作 | Owner |
| --- | --- | --- | --- | --- | --- |
| 目标误解 | Agent 执行了错误任务 | P1 | Trace 回放、用户反馈 | 暂停自动执行，修正任务模板 | FDE |
| 工具误选 | 调错接口 | P1 | 工具调用日志 | 降级到人工确认 | 平台 |
| 参数错误 | 调用失败或写错字段 | P1/P2 | 错误日志 | 修 schema，回放测试 | 工程 |
| 权限越界 | 访问不该访问的数据 | P0 | 权限告警 | 立即停用，安全复查 | 安全 |
| 循环执行 | 重复调用导致成本异常 | P1 | 成本告警 | 限流，设置最大步数 | 平台 |
| 静默失败 | 看似完成但结果不可用 | P2 | 用户反馈、业务校验 | 增加验收检查 | 业务 Owner |

## 上线前检查

- 每个工具是否有权限等级？
- L3/L4 工具是否有审计？
- 是否设置最大步数和成本限制？
- 是否有人工接管条件？
- 是否能回放每次执行？
- 是否有 P0/P1 故障处理流程？

## 使用提醒

Agent 权限表不要只由技术团队填写。业务 Owner、安全、平台和 FDE 都应该参与，因为权限不是技术问题，而是业务责任问题。
