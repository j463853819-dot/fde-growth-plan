# 企业 AI 项目为什么客户不续费

很多企业 AI 项目不是没有上线，而是上线后客户不续费。

原因通常不是模型完全没用，而是客户没有持续感受到价值：用户不常用，指标没变化，维护成本上升，问题没人接，系统慢慢变成一个“曾经很酷”的试点。

> **一句可以带走的判断：客户续费不是因为 AI 很先进，而是因为它持续改善了某个业务结果。**

## 不续费的常见原因

| 原因 | 表现 |
| --- | --- |
| 价值指标不清 | 不知道到底省了什么、赚了什么 |
| 用户采用不足 | 少数人试过，没人长期用 |
| 维护成本过高 | 知识库、Prompt、评测没人维护 |
| 质量不稳定 | 好几次答错后用户不信任 |
| 没有业务 Owner | 系统没人持续推动 |
| 没有扩场景 | 只解决一个小问题，预算难延续 |

## FDE 应该提前做什么

续费不是上线后才考虑。

在项目早期就要定义：

- 基线指标。
- 价值指标。
- 采用指标。
- 运营 Owner。
- 失败样本闭环。
- 扩场景路径。

## 续费价值证明

| 证明项 | 示例 |
| --- | --- |
| 效率改善 | 平均处理时长下降 35% |
| 质量改善 | 错误率下降 20% |
| 采用情况 | 70% 一线用户每周使用 |
| 风险控制 | 高风险场景 100% 转人工 |
| 持续优化 | 每周回放失败样本 |
| 扩张空间 | 可复制到售后、投诉、会员场景 |

客户续费需要证据，不需要更多愿景。

## 最后的判断

AI 项目要续费，必须从“交付项目”变成“运营能力”。

FDE 如果只负责上线，不负责价值证明和运营闭环，项目很容易热闹开场，安静结束。
