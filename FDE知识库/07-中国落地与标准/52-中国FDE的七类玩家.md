# 中国 FDE 的七类玩家

中国 FDE 不是由一种公司定义的。

大模型公司、云厂商、行业 ISV、咨询公司、系统集成商、传统软件公司、企业内部 AI 团队，都可能以不同方式进入 FDE 位置。它们都在解决“AI 如何进企业现场”这个问题，但能力结构不同。

从定义上看，中国 FDE 玩家，是指在企业 AI 落地中承担现场问题发现、方案验证、系统集成、生产交付和持续运营的一类组织或团队。

> **一句可以带走的判断：中国 FDE 的竞争，不是岗位竞争，而是不同组织能力对企业 AI 落地入口的争夺。**

## 七类玩家

| 类型 | 优势 | 风险 |
| --- | --- | --- |
| 大模型公司 | 模型和平台强 | 行业现场不足 |
| 云厂商 | 基础设施和客户资源强 | 容易偏解决方案销售 |
| 行业 ISV | 懂行业流程 | AI 和工程化能力不均 |
| 咨询公司 | 懂业务和组织 | 工程落地弱 |
| 系统集成商 | 集成和交付强 | 产品反哺弱 |
| 传统软件公司 | 有客户和系统入口 | AI 原生能力不足 |
| 企业内部 AI 团队 | 最懂内部现场 | 可能缺外部产品化视角 |

没有一种玩家天然稳赢。

## 谁更接近 FDE

判断标准不是公司类型，而是是否具备四种能力：

- 能进入真实现场。
- 能动手工程验证。
- 能处理生产责任。
- 能把经验沉淀为可复用能力。

只会讲方案，不是 FDE；只会做定制，也不是成熟 FDE。

## 不同玩家的突破点

| 玩家 | 应补能力 |
| --- | --- |
| 大模型公司 | 行业现场和客户接管 |
| 云厂商 | 业务问题定义和产品反哺 |
| ISV | Agent、Eval、Observe |
| 咨询公司 | 工程交付和生产化 |
| 集成商 | 标准化和产品化 |
| 内部团队 | 方法论和外部最佳实践 |

## 最后的判断

中国 FDE 生态会很混杂。

真正能跑出来的，可能不是喊 FDE 最响的团队，而是最早把现场方法、AI 工程、交付证据和商业模型连起来的团队。
