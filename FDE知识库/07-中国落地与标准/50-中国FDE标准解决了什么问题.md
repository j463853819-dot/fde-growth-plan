# 中国 FDE 标准解决了什么问题

FDE 如果只靠个人能力，很难规模化。

一个优秀 FDE 可以把项目做成，但公司要发展，就不能每个项目都依赖个人经验和临场判断。尤其在中国市场，项目多、客户约束重、预算敏感，标准化会直接决定 FDE 能不能变成组织能力。

从定义上看，中国 FDE 标准是一套围绕岗位能力、项目流程、交付证据、生产门禁和客户接管的规范体系。它解决的不是“给岗位取名”，而是让 FDE 工作可识别、可训练、可交付、可复查。

> **一句可以带走的判断：FDE 标准的价值，不是把人框死，而是把个人经验变成组织可以复制的能力。**

## 标准解决五个问题

| 问题 | 标准化作用 |
| --- | --- |
| 岗位边界不清 | 明确 FDE 和售前、交付、咨询的区别 |
| 项目过程不可复查 | 固定 CDEF、门禁和证据包 |
| 质量依赖个人 | 建立能力模型和模板 |
| 客户接管困难 | 标准化运行手册和接管清单 |
| 产品反哺缺失 | 要求复盘和可复用资产沉淀 |

没有标准，FDE 容易变成“谁厉害谁顶上”。

## 标准不等于僵化流程

好的标准应该管住关键风险，而不是限制现场判断。

它要明确：

- 哪些材料必须有。
- 哪些门禁必须过。
- 哪些风险必须记录。
- 哪些 Owner 必须明确。
- 哪些经验必须沉淀。

但具体行业、系统和场景仍然需要 FDE 灵活判断。

## 最小标准包

| 标准项 | 内容 |
| --- | --- |
| 岗位能力标准 | 现场发现、工程实现、AI 生产化、客户接管 |
| 项目流程标准 | Context、Design、Engineer、Feedback |
| 交付证据标准 | 事实表、ADR、评测、SLO、接管清单 |
| 生产门禁标准 | 原型、试点、生产、接管 |
| 复盘标准 | 业务结果、失败样本、产品反哺 |

## 对中国市场的意义

中国 FDE 的难点是项目制太强。如果没有标准，FDE 很容易被每个客户的临时需求拖走。

标准化不是为了把所有项目做成一样，而是让每个项目至少有一样的底座：事实、证据、边界、责任和复盘。
