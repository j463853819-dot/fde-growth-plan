# FDE 知识库

> 面向对 Forward Deployed Engineering（FDE）、企业 AI 落地、AI 交付和工作流改造感兴趣的读者。

这不是一本只解释概念的资料库。

它更想回答一个实际问题：一个 FDE 项目如何从模糊现场、Demo 和试点，走到可上线、可观测、可验收、可接管、可复用的生产系统？

## 当前状态

当前知识库已经形成 13 个专题目录、97 篇正文文章，并新增工程底座导读专题。它覆盖 FDE 认知、项目进入、生产交付、CDEF 细分工具、Agent、人机协作、工具链、行业案例、中国落地、商业化、职业路径、模板、项目决策，以及教材化需要补强的数据工程、运行环境和平台生态。

如果你第一次打开，不建议直接从 01 一路读到 97。更好的入口是：

- [教材全景框架](./00-教材全景框架.md)
- [教材细颗粒目录](./00-教材细颗粒目录.md)
- [阅读路径与分类导航](./00-阅读路径与分类导航.md)

教材全景框架负责说明整套知识体系，教材细颗粒目录负责展开每一章的最后一级内容，阅读路径与分类导航会按读者类型、项目阶段和主题分类告诉你先读什么、后读什么。

快速阅读建议：

1. 先读 `01-MVP十二篇`，建立 FDE 基础认知。
2. 再读 `02-生产化与交付证据`，理解 Demo 如何进入生产。
3. 如果正在做项目，优先读 `10-模板中心` 和 `11-项目决策与避坑`。
4. 然后按兴趣进入 CDEF、Agent、工具链、行业案例、中国落地、商业化和职业路径专题。
5. 如果想按教材方式补工程底座，再读 `12-工程底座与工具生态`。
6. 如果想看完整层级，打开 `00-教材细颗粒目录.md`。
