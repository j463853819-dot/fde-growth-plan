# FDE 面试常见问题

FDE 面试不会只问技术，也不会只问业务。

它更像一次综合判断：你能不能进入陌生现场，能不能定义问题，能不能动手验证，能不能处理生产风险，能不能和客户一起把系统接住。

所以 FDE 面试里的好答案，通常不是最炫的方案。

而是最清楚的推进路径。

> **FDE 面试真正想看的是：你如何在不确定性里推进系统。**

## 一句话定义

FDE 面试考察的是候选人在现场发现、工程实现、AI 生产化、客户沟通和结果负责上的综合能力。

它不是考你背多少概念。

它是看你能不能把一个模糊需求推进成可验证、可运行、可接管的系统。

## 面试官到底在看什么

FDE 面试通常会同时看五件事。

| 能力 | 面试官会怎么观察 |
| --- | --- |
| 问题定义 | 你会不会先确认真实场景，而不是直接做功能 |
| 工程判断 | 你能不能说明数据、接口、权限、架构和实现路径 |
| AI 生产化 | 你是否知道评测、回放、失败样本、人工接管 |
| 客户协作 | 你能否和业务、IT、安全、管理层沟通 |
| 结果负责 | 你是否关心上线、接管、ROI 和复盘 |

面试官不一定期待你每项都满分。

但会警惕一种候选人：方案讲得很漂亮，却没有推进路径。

## 技术类问题

| 问题 | 考察点 | 回答要点 |
| --- | --- | --- |
| 如何设计一个 RAG 系统？ | 数据、检索、评测、权限 | 不只讲向量库，要讲知识来源、权限、引用和评测 |
| Agent 进入生产前要检查什么？ | 工具权限、trace、接管 | 要讲状态机、人工确认、回滚和故障模式 |
| 如何排查 AI 回答质量下降？ | 回放、失败样本、根因分析 | 先查数据和检索，再查 Prompt、模型和用户输入 |
| 如何做私有化部署？ | 环境、依赖、安全、运维 | 要讲部署、升级、日志、监控和客户接管 |

回答不要只讲技术名词。

要讲生产边界。

## 场景类问题

常见题：

“客户说想做一个 AI 助手，你怎么开始？”

好的回答应该包括：

- 不急着做助手。
- 先确认业务场景。
- 看真实流程和数据。
- 区分事实、解释和判断。
- 切一个价值闭环。
- 做 Demo 验证关键假设。
- 补评测、权限和接管。

这类题最怕一上来讲工具。

FDE 面试官真正想看的是：你会不会先找对问题。

## 行为类问题

| 问题 | 面试官想看 |
| --- | --- |
| 讲一次需求不清的项目 | 模糊问题处理能力 |
| 讲一次客户不认可方案 | 沟通和调整能力 |
| 讲一次上线事故 | 责任和复盘能力 |
| 讲一次你拒绝需求 | 边界感 |
| 讲一次你推动多方协作 | 交付承责能力 |

FDE 不是客户说什么都做的人。

能拒绝不该做的需求，也是一种专业能力。

## 作品集追问

如果你带作品集，面试官可能问：

- 真实问题是什么？
- 你怎么确认不是伪需求？
- 为什么选这个切片？
- Demo 验证了什么？
- 进入生产还差什么？
- 如何评测？
- 谁接管？
- 如果客户要扩大范围，你怎么判断？

一个好作品集，要能经得住这些追问。

如果作品集只能展示“我做出来了”，但说不清为什么做、怎么验证、生产还差什么，就很容易被问穿。

## 答题框架

可以用这个结构回答复杂问题：

1. 先确认现场和目标。
2. 再拆事实、约束和风险。
3. 切最小价值闭环。
4. 做工程验证。
5. 设计生产门禁。
6. 让客户接管并复盘。

这个框架的好处是，它不会让你直接跳到方案。

它会先把“为什么做”和“怎么证明”讲清楚。

---

## 实战示范：回答“客户想做销售助手”

不要直接说：

“我会做一个 Agent，接 CRM，然后生成跟进建议。”

这句话不是错。

但它太快了。

它跳过了现场判断。

## 更好的回答

可以这样回答：

“我会先确认销售转化率低发生在哪一段，是线索分配、客户理解、跟进动作，还是复盘反馈。然后看 CRM 字段是否可信，访谈销售和销售主管，找一个最小切片，比如新线索优先级建议。Demo 只验证摘要、优先级和下一步建议是否被销售采纳。试点阶段记录采纳率、修改率和跟进时效。生产前再补权限、日志、评测和接管。”

这个回答不一定最华丽。

但它让面试官看到一条推进路径。

## 为什么这个回答更像 FDE

| 维度 | 回答里体现了什么 |
| --- | --- |
| 现场理解 | 不默认“销售助手”就是正确问题 |
| 问题切片 | 从大助手切到新线索优先级建议 |
| 数据意识 | 检查 CRM 字段是否可信 |
| 用户验证 | 看销售是否采纳和修改 |
| 生产意识 | 补权限、日志、评测和接管 |

FDE 面试里最加分的，不是“我都能做”。

而是“我知道先做什么、暂时不做什么、风险在哪里”。

## 可以带走的判断

FDE 面试不怕你不知道所有答案。

怕的是你只会给一个漂亮方案，却没有推进路径。
