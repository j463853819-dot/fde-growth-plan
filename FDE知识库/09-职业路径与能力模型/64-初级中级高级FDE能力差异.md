# 初级、中级、高级 FDE 能力差异

FDE 的成长，不是从“写小功能”到“写大功能”。

它更像从执行任务，到推进项目，再到设计可复制交付体系。不同阶段的差异，不只在技术深度，也在现场判断、生产责任和产品反哺能力。

从定义上看，FDE 能力成熟度是指一个人能在多大范围内，把模糊现场转化为可运行、可接管、可复用系统能力。

> **一句可以带走的判断：FDE 越高级，越不是自己能做多少事，而是能让多少复杂问题被组织稳定接住。**

## 初级 FDE

初级 FDE 能在指导下完成明确任务。

| 能力 | 表现 |
| --- | --- |
| 现场理解 | 能记录需求和基本流程 |
| 工程实现 | 能做 Demo 和简单集成 |
| AI 能力 | 会用 Prompt、RAG 或 Agent 工具 |
| 交付意识 | 知道需要评测和文档 |

初级阶段最重要的是别只追求炫技，要学会记录事实和约束。

## 中级 FDE

中级 FDE 能独立推进一个价值切片。

| 能力 | 表现 |
| --- | --- |
| 问题定义 | 能从客户说法中拆出真实问题 |
| 方案设计 | 能切最小价值闭环 |
| 工程推进 | 能从 Demo 走到试点 |
| 生产化 | 能设计评测、权限、日志和回滚 |
| 协作 | 能协调业务、工程、安全和客户 |

中级 FDE 的标志，是能让项目不靠运气推进。

## 高级 FDE

高级 FDE 能设计体系。

| 能力 | 表现 |
| --- | --- |
| 战略判断 | 能选择高价值行业和场景 |
| 组织设计 | 能搭建 FDU 或交付小队 |
| 产品反哺 | 能把个案抽象成平台能力 |
| 商业闭环 | 能定义 ROI、定价和续费逻辑 |
| 方法沉淀 | 能训练他人、建立标准 |

高级 FDE 不只是项目高手，而是方法和组织能力的建设者。

## 成长路径

| 阶段 | 关键突破 |
| --- | --- |
| 初级到中级 | 从执行功能到定义切片 |
| 中级到高级 | 从推进项目到沉淀体系 |
| 高级之后 | 从个人交付到组织复制 |

## 自评问题

- 我能不能独立确认真实问题？
- 我能不能设计 Demo 的验收标准？
- 我能不能说明系统进生产还缺什么？
- 我能不能让客户接管？
- 我能不能把这次项目经验变成模板？

FDE 的成长，最终会回到一个问题：你是在解决一个项目，还是在提高组织解决这类项目的能力？
