# 03-CDEF 方法论

CDEF 是这个知识库的核心方法论资产，用来解释 FDE 如何从混沌现场推进到可交付系统。

它不是一套抽象流程图，而是一条项目推进路径：先读懂现场，再设计切片，然后工程验证，最后把反馈沉淀为产品和组织能力。

## 四阶段

| 阶段 | 核心问题 | 主要产物 |
| --- | --- | --- |
| Context | 现场到底发生了什么 | 事实约束表、角色地图、问题模型 |
| Design | 哪个切片最值得验证 | 需求切片画布、方案草图、门禁标准 |
| Engineer | 如何从 Demo 走到可运行系统 | 原型、评测、ADR、生产准入证据 |
| Feedback | 如何证明有效并反哺产品 | 指标复盘、客户接管、产品反哺清单 |
