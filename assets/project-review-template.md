# FDE 项目副驾驶输出模板

这个模板用于项目评审、生产检查、交付模板生成和作品集打磨。它不是固定格式，可以按用户问题裁剪，但核心判断不能缺。

## 3. 模板生成原则

生成任何 FDE 模板时，必须区分：

- 已知事实
- 待验证假设
- 缺失信息
- 建议下一步

不要把用户没有提供的信息写成确定事实。
